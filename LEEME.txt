WEB YU-GI-OH! — TAG FORCE 2 + DUEL TRANSER

CAMBIOS
- Duel Transer carga los packs, rarezas y condiciones desde Duel_Transer_packs.txt del repositorio público.
- Se intenta primero el TXT local y luego la versión pública de GitHub como respaldo.
- Los nombres y el orden salen del TXT; se valida que haya al menos 40 packs antes de reemplazar la base integrada.
- Las rarezas se colorean como en Tag Force 2: Ultra/Secret = dorado, Super = plateado, Rare = bronce, Common = normal.
- Se quitaron las comprobaciones/diagnósticos automáticos de imágenes al iniciar.
- Las portadas de Duel Transer se buscan solo en images/packs-duel-transer/01.jpg ... 48.jpg. No se consultan APIs para portadas.

EJECUCIÓN
1. Extraer todo el ZIP.
2. Mantener conexión a Internet (la web consulta YGOPRODeck para imágenes/datos de cartas).
3. Ejecutar Abrir_Base_YuGiOh.bat.

PORTADAS
Copiar las 48 imágenes locales en images/packs-duel-transer/ y nombrarlas 01.jpg, 02.jpg, ... 48.jpg en el mismo orden que el TXT. Si falta alguna, se verá una portada genérica.

NOTA
Si la web se publica en GitHub Pages, asegurarse de que Duel_Transer_packs.txt esté en la raíz del repositorio.
